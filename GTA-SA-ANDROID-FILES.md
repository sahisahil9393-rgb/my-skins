# GTA San Andreas Android files

This repository contains the merged Android game files and mod files from the source package and the public file manifest.

## Layout

- Files under `files/` follow the paths listed by the source file manifest.
- Additional mod files such as `cleo/`, `configs/`, and `mods/` retain their original paths from the source package.
- Files larger than GitHub's normal repository file limit are attached individually to the GitHub Release listed below.
- `gta-sa-android-release-manifest.json` maps each release asset back to its original in-game path.

## Large files Release

The large-file assets are published in the `gta-sa-android-files-v1.0.0` release.
